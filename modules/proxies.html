资源管理

代理库

出口资源池与健康巡检

全部出口资源集中管理，一行一条，批量检测与删除；健康状态实时标色。环境引用后自动享受故障转移——当前线路失联，秒级切换备用线路。

能力一览

能为你做什么

批量导入

支持按行粘贴常见格式，快速建立资源池。

一键批量检测

显示出口 IP、地理位置与连接延迟，失效资源批量剔除。

健康巡检

定时复检，IP 变化与连接失败自动标色提醒。

故障转移

每个环境可配置多条备用线路，主线路失效自动切换。

动态代理渠道

接入渠道 API 按链接自动提取新 IP，每次启动都是新出口。

启动预检

环境启动前自动检测代理可用性，不通过则取消启动，避免真实 IP 泄漏。

界面实拍

真实界面，所见即所得

上手方式

几步就能用起来

  1. 1

    添加代理：粘贴或导入代理列表，支持 HTTP / SOCKS5 与账号密码。

  2. 2

    批量检测：一键检测全部条目，查看出口 IP 与延迟。

  3. 3

    绑定环境：为环境选择主代理与备用线路。

  4. 4

    保持巡检：定时复检，异常自动标色，问题提前暴露。
