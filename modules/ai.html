AI 助手

对话式智能操作助手

用自然语言指挥整个软件：「有多少环境在运行？」「对全部环境做一次体检」——AI 在独立窗口中直接调用内置工具完成任务，写操作先确认、执行后可撤回，全程可控。

能力一览

能为你做什么

任意兼容服务

OpenAI / DeepSeek / 通义 / 本地 Ollama / One-API 等均可接入。

与 MCP 同源

环境启停、批量体检、代理检测、流程与养号等内置工具直接调用。

独立窗口与多入口

侧栏、命令面板（Ctrl+K）或托盘菜单随时唤起；独立窗口可与主窗口并排，互不打断。

流式回复

回答增量呈现，工具调用卡片实时显示执行状态。

先确认，可撤回

写操作执行前弹出确认（120 秒未响应自动拒绝），完成后可在工具卡一键撤回。

对话持久化

历史自动保留，关闭窗口再打开可以继续之前的对话。

上手方式

几步就能用起来

  1. 1

    配置服务：在系统设置中填入 Base URL、API Key 与模型名。

  2. 2

    随手唤起：从侧栏、命令面板（Ctrl+K）或托盘菜单打开独立的 AI 助手窗口。

  3. 3

    直接提问：例如「批量检测代理库，列出失效的」。

  4. 4

    确认与撤回：写操作先审阅确认；执行后不满意，在工具卡一键撤回。
