常见问题

你可能想知道

我的数据保存在哪里？会上传云端吗？
环境数据、代理配置与账号凭据默认全部保存在本机，不上传任何服务器。同时支持 WebDAV 备份到你自己的存储空间，以及本地备份与一键恢复，数据始终由你掌控。
支持哪些类型的代理？
支持 HTTP 与 SOCKS5 代理，可带账号密码；代理库集中管理全部出口资源，配合动态代理渠道按链接自动提取新 IP。启动环境前会自动做代理预检，检测不通过则取消启动，避免真实 IP 泄漏。
可以在多台电脑上协作使用吗？
支持。局域网内一台电脑作为主机运行环境与数据，团队成员在其他电脑安装同款客户端并连接主机，即可共用同一套环境与账户；配合多用户权限与审计日志，团队协作可管可控。
如何通过脚本或程序驱动浏览器？
软件内置本地 HTTP API 与 MCP 端点，Playwright 可直接接入运行中的环境；同时提供可视化的「自动化流程」与「任务编排」，不写代码也能完成定时任务与批量流水线。
忘记主密码怎么办？
主密码用于保护软件访问。若遗忘，可通过安全重置流程在冷静期后恢复访问，已保存的环境数据不受影响；建议同时启用备份中心的定期备份。
支持哪些系统？
当前提供 Windows 版本，支持 Windows 10 / 11（64 位）。
