快速开始

安装与首次启动

  1. 前往官网下载页获取 Windows 安装包（约 509 MB），双击运行并按向导完成安装。
  2. 首次启动会看到模式选择界面，按你的使用方式二选一：
    • 本机使用：在本机创建与运行环境，适合绝大多数个人用户。
    • 连接主机：作为客户端接入局域网内的团队主机，详见第 07 章。
  3. 选择「本机使用」后应用会自动重启一次，随后进入完整功能界面。

如果 Windows 弹出「已保护你的电脑」提示（SmartScreen），点击「更多信息 → 仍要运行」即可继续安装。

软件由五组、共 23 个模块组成，左侧导航一屏直达。先看一遍总览，知道什么功能在哪里，后续查找会顺手很多。

三步启动第一个环境

  1. 点击「新建环境」并命名；不配置代理也能先用直连体验。
  2. 点击环境对应的启动按钮，等待独立浏览器窗口打开。
  3. 窗口就绪后正常登录、浏览即可；退出环境时 Cookie 与登录态都会被保留。
02

环境管理

新建环境

点击「新建环境」，填写或选择以下信息：

  • 名称：建议带上店铺与市场信息（如「NovaMarket 美国店 01」），列表里一眼可辨。
  • 平台与浏览器品牌：默认由指纹种子自动生成，也可以手动指定。
  • 语言与时区：与目标市场保持一致。
  • 代理：从代理库选择、手动填写，或先用直连；支持接入动态代理渠道。
  • 分组：用于列表归类与批量筛选。

需要多个环境时使用批量创建一次生成，每个环境的命名与指纹相互独立，无需重复配置。

启动与停止

  • 点击启动按钮即可打开独立浏览器窗口，启动页可以按环境单独配置。
  • 支持批量启动、批量停止；多开场景下可用窗口一键排列快速整理桌面。
  • 配置了代理的环境会在启动前自动做代理预检，检测不通过会取消启动，从源头避免真实 IP 泄漏。
  • 退出环境后 Cookie、缓存与登录态保留，下次启动直接续用。

分组、筛选与回收站

通过分组与标签整理环境，配合搜索快速定位目标。删除的环境会先进入回收站，可随时还原，确认无误后再彻底清除。

环境保险锁

对重要环境开启保险锁后，删除、修改等敏感操作会被拦截。多人共用一台主机时，给核心店铺环境上锁可以有效防止误操作。

磁盘占用与缓存清理

环境列表中可以看到每个环境的磁盘占用情况。长期运行后可定期清理缓存释放空间，账号数据与登录态不受影响。

启动场景与预览墙

  • 启动场景：把一组常用环境保存为场景，上班第一件事就是「一键多开」。
  • 预览墙：把运行中的环境以窗口矩阵缩略图铺开，快速巡检每个环境的当前画面。
03

指纹与模板

种子驱动指纹

每个环境由一串「种子」驱动生成整套指纹：系统平台、浏览器品牌与版本、CPU 核心数、语言、时区彼此协调一致， 不会出现「Windows 却报告英文系统与东京时区」这类自相矛盾的组合。

种子不同的环境，指纹完全独立；同一个环境每次启动保持一致，不会随机漂移，账号登录环境长期稳定。

指纹模板与环境模板

  • 指纹模板：把一套指纹参数（平台、品牌、语言、时区）保存为模板，新建环境时直接套用，或批量应用到已有环境。
  • 环境模板：把代理策略、启动页、分组等整套配置一起沉淀，适合连锁店群与标准化交付场景。

模板让「调好一个、复制一百个」成为常规操作，也是团队之间传递配置经验的最佳载体。

启动自检页

可以按环境开启启动后自动打开自检页，快速核对关键指纹项是否一致、是否存在异常泄漏迹象。养成「新环境先自检、再登录」的习惯，异常会在上线前就被发现。

建议让出口 IP、语言与时区三者指向同一地区，例如美国店铺就配美国代理 + en-US + America/New_York。

04

代理管理

添加代理

在「代理库」点击添加，选择类型（HTTP / SOCKS5），填写主机、端口与账号密码（如有）。添加完成后建议立即执行一次连通检测，确认线路可用。

代理库与健康总览

  • 顶部健康总览实时呈现「健康 / IP 变化 / 失败」三态分布，出口资源质量一眼可见。
  • 一键体检会批量检测全部代理，每条代理保留检测历史，线路是否稳定有据可查。
  • 代理是共享资产：在代理库修改一次，所有引用它的环境同步生效。

动态代理渠道

使用按量计费的动态代理时，可以配置渠道提取链接，让软件按需自动提取新的出口 IP，无需手动替换。

出口检测

在代理或环境上执行出口检测，可以验证真实出口 IP、归属地与生效时区，确认与目标市场精确匹配。

启动前预检与故障转移

  • 配置代理的环境在启动前会自动预检；检测不通过时取消启动并给出提示，确保流量不会在代理失效时泄漏真实 IP。
  • 可以为代理配置备用线路，主线路失联时自动切换，环境运行不中断。

定期巡检

结合定时任务可以定期执行三类巡检：线路健康、代理出口与登录状态。发现异常会通过通知中心提醒，让问题在影响账号之前被处理。

05

自动化

无界提供三种接入方式，从零代码到全代码，按你的团队情况自由选择。

本地 HTTP API

软件运行时会开启本地接口（默认 127.0.0.1:50325，被占用时自动顺延），脚本可以直接启动、停止环境并获取调试端点：

HTTP API 127.0.0.1:50325 
# 列出全部环境与运行状态
curl http://127.0.0.1:50325/api/envs

# 启动环境并获取 CDP 调试端点
curl -X POST http://127.0.0.1:50325/api/envs/NovaMarket/start

# 停止环境
curl -X POST http://127.0.0.1:50325/api/envs/NovaMarket/stop

MCP 端点（AI 客户端）

内置 MCP（Model Context Protocol）端点，Claude Desktop、Cursor 等支持 MCP 的 AI 客户端可以直接调用环境能力，让 AI 帮你完成批量操作与日常运维。

Playwright 直连

任何支持 CDP 的自动化框架都能接入运行中的环境，以 Playwright 为例：

Playwright connect-over-cdp.mjs 
import { chromium } from 'playwright'

// 接入运行中的环境（自动等待调试端口就绪）
const browser = await chromium.connectOverCDP(cdpEndpoint)
const page = browser.contexts()[0].pages()[0]
await page.goto('https://example.com')

自动化流程

不写代码也可以做自动化：在环境中把操作演示一遍，操作录制会生成可回放的流程； 也可以在可视化编辑器中编排多步骤任务，把流程绑定到指定环境，下次一键执行。

任务编排与定时任务

  • 任务编排：把多个任务组合成流水线，例如「启动环境 → 打开店铺 → 截图存档 → 停止环境」。
  • 定时任务：支持启动、停止、巡检、执行流程与快照五种类型，可按每日、工作日或单次执行，适合早晚班自动值守。
  • 养号保活：定时让环境模拟真实浏览行为，维持账号活跃度与登录态。
  • 任务中心：所有任务的进度与历史集中呈现，失败原因可回溯。
06

账号保险箱

保存凭据

每条凭据包含名称、站点、账号、密码、备注与标签，加密保存在本机。环境多、账号多的时候，配合标签检索比翻表格快得多。

动态口令（TOTP）

添加凭据时可以录入两步验证密钥（Base32 格式），保险箱会像验证器应用一样实时生成 30 秒动态口令，登录时随用随取，不必再掏出手机。

一键填充

在环境中遇到登录页时，可以直接从保险箱选择对应凭据完成填充，无需复制粘贴密码，既快又降低凭据泄露风险。

保险箱与主密码联动：开启主密码锁后，每次启动软件都需要验证身份，才能访问其中保存的凭据。

07

团队协作

两种工作模式

  • 主机模式：由一台性能较好的电脑运行环境与数据，在系统设置中开启共享，局域网内的成员即可连接使用。
  • 客户端模式：团队成员在自己电脑安装同款客户端，首次启动选择「连接主机」并填写主机地址，即可共用同一套环境、代理与账号资产。

环境始终运行在主机上，成员客户端负责操作与查看，硬件资源不重复投入，一套环境池服务整个团队。

成员与权限

在「团队协作」页创建成员账户并分配权限：谁能查看、谁能启动、谁能修改资源，按角色控制，避免误操作。

审计日志

成员的关键操作全程留痕，支持按成员、类型与时间筛选，并可导出归档。出了问题，能快速定位到人、事与时间。

08

安全与备份

主密码锁

  • 设置主密码后，每次启动软件都需要验证，防止他人打开电脑直接查看环境与凭据。
  • 支持自动锁定与严格模式：离开电脑一段时间后自动上锁，回来后重新验证。
  • 如果忘记主密码，可通过重置流程在经过冷静期后重新获得访问权限；已保存的环境数据不受影响。

备份中心

  • 支持本地备份与 WebDAV 备份，可以备份到自己的 NAS 或云盘，数据始终由自己掌控。
  • 恢复支持整体回滚；换新电脑时，先安装软件再还原备份，即可无缝迁移全部环境与配置。

AI 助手

对话式操作助手，软件内名为「无界AI助手」（左侧导航「系统」分组）：用自然语言描述需求，它直接调用软件内置能力完成任务，适合批量操作与快速排查。在「系统设置 → 无界AI助手」中接入模型服务即可启用。

  • 随手唤起：主窗口侧栏、命令面板（Ctrl+K）或托盘菜单，都会打开独立的 AI 助手窗口，可与主窗口并排使用，互不打断。
  • 先确认，可撤回：涉及改动的写操作执行前弹出确认；执行完成后，工具卡上提供「撤回」按钮，误操作一键回退。
  • 对话持久化：历史记录自动保留，关闭窗口再打开可以继续之前的对话。

09

常见问题

安装时 Windows 提示「已保护你的电脑」，还能继续吗？
这是 SmartScreen 对尚未广泛下载的安装包的常规提示，并非病毒警告。点击「更多信息」，再选择「仍要运行」即可继续安装。
环境启动失败并提示「代理预检失败」怎么办？
说明该环境绑定的代理当前不可用。请先在代理库对它执行检测，确认主机、端口与账号密码正确；如果暂时不需要代理，可以改为直连再启动。预检机制的作用，是避免流量在代理失效时泄漏真实 IP。
数据保存在哪里？换电脑怎么迁移？
全部数据默认保存在本机，不上传云端。迁移到新电脑时：旧电脑在备份中心导出备份，新电脑安装软件后还原即可，环境、代理与凭据一并迁移。
怎么让脚本或 AI 驱动这些环境？
使用本地 HTTP API（默认 127.0.0.1:50325）或 MCP 端点接入；Playwright 等自动化框架可通过 CDP 直连运行中的环境。完整示例见「05 · 自动化」章节。
一台电脑同时运行多少个环境比较合适？
取决于内存与 CPU 配置。建议从少量开始逐步增加，观察系统负载；长时间批量运行时，可以配合任务编排控制并发节奏，稳定优先。
忘记主密码了怎么办？
在解锁界面选择重置流程，经过冷静期后即可重新设置主密码；已有环境数据不会被清除。建议同时开启备份中心的定期备份，做到双保险。

没有找到答案？从侧栏、命令面板（Ctrl+K）或托盘菜单打开「无界AI助手」直接提问，它熟悉全部模块的用法。
